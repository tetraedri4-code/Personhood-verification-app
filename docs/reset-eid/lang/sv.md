# Skydda din e-legitimation

Appen visar den här sidan när den rekommenderar att du skyddar din e-legitimation: när din registrering
avvisas för att någon redan har registrerat sig med din identitet, när du anmäler "det var inte jag", och
när någon begär att ersätta hemligheten i din telefon utan att du vet om det.

## Varför e-legitimationen kommer först

Appen litar på den som kan logga in med din e-legitimation **och** har appen. Om någon annan fortfarande
kan logga in som du kan de häva en avstängning eller avvisa din ersättning igen. Stäng därför först
e-legitimationen, skaffa nya inloggningsmedel och använd appen först därefter:

1. **Stäng (spärra) de inloggningsmedel som kan ha använts**: inloggningsappen, id-kortets
   certifikat, mobilt id eller bankkoder, vad du än använder. Sidan för ditt land nedan visar hur, med
   telefonnummer.
2. **Polisanmäl brottet.** Att använda någon annans identitet är ett brott i alla medlemsstater.
3. **Skaffa nya inloggningsmedel** från utfärdaren.
4. **I appen:** `pop holder replace --not-me`, med inloggning med de **nya** inloggningsmedlen.

Om avstängningen hävs igen efter att du har skyddat din e-legitimation har någon fortfarande ett sätt att
logga in som du: kontakta polisen och utfärdaren av din e-legitimation.

## Du har rätt att få den stängd

EU:s regler kräver att varje e-legitimationssystem som anmälts för gränsöverskridande användning gör det
möjligt att spärra eller återkalla ett identifieringsmedel "i rätt tid och på ett effektivt sätt"
(kommissionens genomförandeförordning (EU) 2015/1502, bilagan, punkt 2.2.3). Nationell lag säger ofta mer;
sidan för ditt land nämner den där den har kontrollerats.

Landssidorna kontrollerades den 19–20 november 2026 mot utfärdarnas och myndigheternas egna sidor, som
länkas. Telefonnummer och öppettider ändras: lita på den länkade sidan. Där något inte kunde kontrolleras
står det på sidan.
