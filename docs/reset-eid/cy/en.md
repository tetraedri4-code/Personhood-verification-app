# Cyprus

## 1. Close the eID means

**ID card.** Report the loss to the police and apply for a new card; it takes about 10 working days
([Civil Registry and Migration Department](https://moi.gov.cy/moi/CRMD/crmd.nsf/All/9360684288FC9CE3C22588FA0046196E)).

## 2. Report to the police

Since 8 June 2026 the police's DigiPol portal, reached through GOV.CY, also takes declarations of a lost ID
card, according to news reports
([Politis](https://en.politis.com.cy/news/cy-news/1011845/cyprus-police-launch-digipol-portal-with-more-than-30-online-services)).

## 3. Get new means

Apply for a new ID card at the Civil Registry and Migration Department
([CRMD](https://moi.gov.cy/moi/CRMD/crmd.nsf/All/9360684288FC9CE3C22588FA0046196E)).
