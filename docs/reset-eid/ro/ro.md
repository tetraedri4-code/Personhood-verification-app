# România

## 1. Închideți mijloacele eID

**Cartea electronică de identitate (CEI).** Certificatele ei servesc la autentificarea în relația cu
autoritățile ([DJEP Iași](https://www.djep-iasi.ro/wp-content/uploads/2025/08/GENERALITATI-CEI.pdf)). Potrivit
unei asociații de consumatori, declarați pierderea la ghișeu, de regulă în 15 zile, și anunțați banca
([InfoCons](https://infocons.ro/ai-ramas-fara-buletin-afla-care-sunt-pasii-de-urmat-si-cum-poti-obtine-noua-carte-electronica-de-identitate-cei-infocons-protectia-consumatorilor-te-informeaza/)).

**ROeID** este autentificarea unică pentru serviciile publice ([ROeID](https://www.roeid.ro/)).

## 2. Sesizați poliția

Anunțați poliția dacă bănuiți un furt
([InfoCons](https://infocons.ro/ai-ramas-fara-buletin-afla-care-sunt-pasii-de-urmat-si-cum-poti-obtine-noua-carte-electronica-de-identitate-cei-infocons-protectia-consumatorilor-te-informeaza/)).

## 3. Obțineți mijloace noi

Faceți o programare pentru o nouă CEI pe [hub-ul Ministerului Afacerilor Interne](https://hub.mai.gov.ro/);
o carte eliberată din nou costă 70 de lei ([DJEP Iași](https://www.djep-iasi.ro/wp-content/uploads/2025/08/GENERALITATI-CEI.pdf)).

## Neverificat

Cum se suspendă certificatele CEI sau cum se blochează un cont ROeID. Această pagină se bazează parțial pe
o asociație de consumatori, nu pe o sursă oficială.
