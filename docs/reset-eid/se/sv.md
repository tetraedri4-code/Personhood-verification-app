# Sverige

## 1. Stäng e-legitimationen

**BankID.** BankID spärras via banken som har utfärdat det. Spärra det genast, per telefon eller på ett
bankkontor. Till exempel är Swedbanks spärrlinje **08 411 10 11** öppen dygnet runt
([Swedbank](https://www.swedbank.se/om-oss/sakerhet-och-bedragerier/sparrhjalp)). Använd din egen banks
spärrnummer.

**Freja eID.** Ring spärrlinjen **+46 8-27 00 29**, öppen dygnet runt, endast för akuta spärrar
([Freja](https://frejaeid.com/freja-support/)).

**Id-kort eller pass.** Om det har förlorats eller stulits, ring polisen på **114 14** eller besök en
polisstation ([Polisen](https://polisen.se/tjanster-tillstand/pass-och-nationellt-id-kort/)).

Använd aldrig din e-legitimation på uppmaning av någon som ringer dig
([Skatteverket](https://skatteverket.se/servicelankar/otherlanguages/englishengelska/news/news2025/news/threewaystoreducetheriskofidentitytheft.5.6491ed82199c4722dae51e.html)).

## 2. Polisanmäl

Anmäl andra brott, som missbruk av din identitet, via polisens e-tjänster eller på 114 14
([Polisen](https://polisen.se/utsatt-for-brott/polisanmalan/)).

## 3. Skaffa nya inloggningsmedel

Beställ ett nytt BankID från din bank. Boka tid hos polisen för nytt id-kort eller pass
([Polisen](https://polisen.se/tjanster-tillstand/pass-och-nationellt-id-kort/)).

## Inte kontrollerat

Spärrnummer till andra banker än Swedbank.
