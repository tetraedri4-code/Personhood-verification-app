# Greece

## 1. Close the eID means

**ID card.** Declare a lost ID card so that it is cancelled. A theft is reported only in person at a
police station, not electronically ([gov.gr](https://www.gov.gr/org/astynomia/ellenes-tou-exoterikou/loss-id)).
According to news reports, the gov.gr Wallet revokes the digital ID automatically once you report the
document lost ([Greek City Times](https://greekcitytimes.com/2026/01/16/gov-gr-wallet-upgrade-real-time-alerts-for-revoked-ids-new-features/)).

**TAXISnet codes.** Change your password with "Αλλαγή κωδικού"; this needs the current password
([iefimerida, 2020](https://www.iefimerida.gr/ellada/psifiakis-diakybernisis-allaxete-kodikoys-taxisnet)).
For help, the e-services line of the General Secretariat for Information Systems is **213-133 3033**
([GSIS](https://www.gsis.gr/)).

## 2. Report to the police

Report a theft in person at a police station ([gov.gr](https://www.gov.gr/org/astynomia/ellenes-tou-exoterikou/loss-id)).

## 3. Get new means

Apply for a new ID card at the police.
